# Font assets

The site self-hosts two normal-style variable WOFF2 fonts, covering weights 100–900 and the Latin text used by this portfolio. Downloaded from Google Fonts on 31 October 2026. The files are unmodified; both fonts use the SIL Open Font License 1.1. Their full licence files are included alongside them.

No runtime request to Google Fonts or another font CDN is required. Keep these files and licences together when copying the website.

Source stylesheet: https://fonts.googleapis.com/css2?family=Inter:wght@100..900&family=Montserrat:wght@100..900&display=swap
